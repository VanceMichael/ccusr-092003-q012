# 领域资料

桥梁节段从预拼到浅水运输、倒驳和吊装有固定依赖，航道窗口同时受水位和水电站调度影响。本系统以**构件版本**与**既定安装序列（合龙顺序）**为主线，把预拼验收、船舶载荷、航道水深、倒驳交接、缆索吊能力、两岸条件与环保禁限时段统一收敛为签发前的闸门判定。

## 核心约束

1. **前序证据与当前窗口同时成立，下一动作才可签发。**
   每个许可（`permits`）保存完整闸门报告（`gate_report_json`），逐项列出通过/失败原因。
2. **证据只追加。** 制造、预拼验收、运输、倒驳交接、安装均为 `evidence_events` 事件；复检是指向旧证据（`supersedes_event`）的新事件（`disposition=pass|fail`），历史永不覆盖。
3. **变化即重算。** 水位窗口发布、设备状态变化、复检结论、环保禁令写入时，立即生成 `impact_reports`：吊销不再成立的生效许可、释放资源、列出受影响节段及其合龙顺序阻断关系。
4. **同一资源并发只准一个生效。** `resource_grants` 上的部分唯一索引保证同一船舶/缆索吊至多一条未释放授权；冲突申请返回 409 且不留许可记录。
5. **合龙后可反查。** 合龙节点（`closures`）要求序列内全部节段安装到位；`GET /segments/{ref}/trace` 返回该节段的版本、分阶段证据（含复检链）与全部许可/吊销留痕。

## 动作与前序

| 动作 | 资源 | 前序证据 | 额外闸门 |
| --- | --- | --- | --- |
| transport 运输 | vessel | fabricated, accepted | 船舶载荷、吃水≤航道水深、窗口开启、禁航 |
| transfer 倒驳交接 | vessel | transported | 同上 |
| hoist 起吊安装 | hoist | transferred | 缆索吊能力、南北两岸均具备、前序节段已安装、禁吊 |

当前版本上任一证据的最新复检为不通过时，后续动作全部阻断；升版（`segment_revisions`）后旧版本证据不再满足闸门。

外部主体使用不含真实身份信息的引用编号。交换时间采用带偏移量的 ISO 8601 字符串，原始材料只保存受控引用或 `sha256:` 摘要。`contracts/entities.json` 中的字段名称属于稳定接口约定，运行时数据文件位置由 `DATABASE_PATH` 决定。
